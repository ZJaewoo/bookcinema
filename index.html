Nanobanana — AI 이미지 생성

STEP 1 · AI 이미지 도구
🔗 사이트 바로가기
1
책 장면 선정

영상으로 만들고 싶은 장면 1~3문장을 책에서 선택합니다. 감정이 강하거나 시각적 묘사가 풍부한 장면이 좋습니다.

2
Nanobanana 접속 → 새 프로젝트 생성

우측 상단 [새 이미지 생성] 버튼 클릭 → 스타일 설정 화면 진입합니다.

3
프롬프트 입력

장면의 분위기 · 색감 · 시점을 키워드로 입력합니다.
예) "책상 위 촛불, 낡은 편지, 골든아워, 필름 그레인, 시네마틱"

4
스타일 설정

Cinematic / Film Grain 스타일을 권장합니다. 비율은 16:9(가로) 또는 9:16(세로 숏폼) 선택.

5
이미지 선별 및 저장

최소 3장 이상 생성 후 가장 영상 느낌이 강한 이미지 1장을 선택합니다. 고화질로 다운로드 후 다음 단계로 이동.

💡 팁: "책 제목 + 핵심 감정 단어 + 시네마틱" 형식으로 프롬프트를 쓰면 일관된 분위기를 유지할 수 있어요.
🤖

ChatGPT — 프롬프트 최적화

STEP 2 · 프롬프트 엔지니어링
🔗 사이트 바로가기
1
장면 텍스트 붙여넣기

선택한 책 장면(1~3문장)을 ChatGPT 대화창에 붙여넣습니다.

2
프롬프트 변환 요청

아래 문장을 그대로 사용하세요:
"이 장면을 Veo 3.1용 영상 생성 프롬프트로 영어로 작성해줘. 카메라 무브먼트, 조명, 분위기를 포함해서 100자 내외로."

3
카메라 무브먼트 추가

프롬프트에 카메라 움직임을 명시하세요.
예) slow zoom in / dolly forward / pan right / static shot

4
조건 세부화

날씨 · 조명 · 시간대를 추가합니다.
예) golden hour light / rainy night / foggy morning / candlelight interior

5
최종 영어 프롬프트 정리

100자 내외의 영어 프롬프트를 복사해 메모장에 저장합니다. Veo 3.1 입력에 바로 사용할 수 있습니다.

💡 팁: ChatGPT에게 "더 영화적으로", "더 감성적으로" 라고 추가 요청하면 프롬프트 품질이 높아집니다.
🎬

Veo 3.1 — AI 영상 생성

STEP 3 · Google DeepMind AI 영상 모델
🔗 사이트 바로가기
1
Google Flow(VideoFX) 접속

Google 계정으로 로그인 후 VideoFX / Google Flow에서 Veo 3.1 모델을 선택합니다. (Google One AI Premium 구독 또는 waitlist 신청 필요)

2
이미지 업로드 (Image-to-Video)

Nanobanana에서 저장한 이미지를 업로드합니다. [+Image] 버튼 클릭 → 이미지 선택.

3
프롬프트 입력

ChatGPT로 최적화한 영어 프롬프트를 텍스트 입력창에 붙여넣습니다. Veo 3.1은 음향 효과와 배경음 자동 생성도 지원합니다.

4
영상 설정

영상 길이: 5초 또는 8초 선택
해상도: 1080p 권장
종횡비: 9:16(세로) 또는 16:9(가로)

5
생성 및 저장

[Generate] 클릭 → 약 30~60초 대기 → 결과 영상 미리보기 → 마음에 들면 고화질 다운로드. 마음에 들지 않으면 프롬프트를 수정하여 재시도합니다.

6
여러 클립 생성

책의 다른 장면으로 2~5개의 클립을 생성합니다. CapCut에서 이어 붙여 완성도 높은 북 트레일러를 만들 수 있습니다.

💡 Veo 3.1 특징: Google DeepMind의 최신 영상 생성 모델로, 자연스러운 움직임과 물리 법칙을 이해하는 영상을 생성합니다. 특히 오디오 동기화가 뛰어나 배경음이 자동으로 생성됩니다.
✂️

CapCut — 숏폼 편집 완성

STEP 4 · 최종 편집 워크플로우
🔗 사이트 바로가기
1
새 프로젝트 생성

CapCut 앱 또는 웹 실행 → [새 프로젝트] → 비율 설정: 9:16 세로(숏폼) 또는 16:9 가로 선택.

2
클립 배치

Veo 3.1 영상 클립들을 스토리 순서대로 타임라인에 드래그합니다. 전체 길이는 30초~60초를 목표로 하세요.

3
트랜지션 추가

클립 사이 [+] 버튼 → 트랜지션 메뉴 → Fade 또는 Dissolve 선택. 지속시간: 0.5초 권장.

4
자막 추가

[텍스트] → [자막 추가] → 책의 핵심 문장을 입력합니다. 폰트: 명조 / 감성 세리프 권장. 텍스트 애니메이션: Fade In 적용.

5
배경음악 추가

[오디오] → [음악] → 저작권 프리 음원 선택. 분위기에 맞는 클래식 / 앰비언트 장르 권장. Veo 3.1 자동 음향이 있으면 음량 조절만 하세요.

6
색보정 LUT 적용

[필터] → Cinematic 또는 Moody 필터 선택. 강도: 40~60% 권장. 원본 영상 느낌을 해치지 않는 선에서 적용.

7
볼륨 밸런스 조정

배경음악 볼륨: -12dB (약 30%)로 설정. Veo 자동 음향이 있으면 메인 트랙으로 유지하고 음악은 더 줄이세요.

8
페이드 아웃 효과

첫 클립 시작과 마지막 클립 끝에 페이드 인/아웃 효과를 적용합니다. 오디오도 끝부분에서 서서히 줄어들도록 설정.

9
최종 내보내기

[내보내기] → 해상도: 1080p → 프레임: 30fps → 저장. 파일을 北CINEMA 갤러리에 업로드하세요!

💡 팁: CapCut의 [자동 자막] 기능으로 AI가 자동으로 자막을 생성해줍니다. 책 제목과 저자 크레딧도 마지막 장면에 넣어주세요.

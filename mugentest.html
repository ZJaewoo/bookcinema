🍌

Nanobanana 이미지 생성

STEP 1 · AI 이미지 도구

  • 1책에서 영상화할 장면 1~3문장 선정
  • 2Nanobanana 접속 후 새 프로젝트 생성
  • 3장면 분위기·색감·시점 키워드 입력
  • 4스타일: Cinematic / Film Grain 권장
  • 516:9 또는 9:16 비율로 이미지 생성
  • 6최소 3장 생성 후 최적 이미지 선별
🤖

ChatGPT 프롬프트 최적화

STEP 2 · 프롬프트 엔지니어링

  • 1선정한 장면을 ChatGPT에 붙여넣기
  • 2"이 장면을 Runway용 영상 프롬프트로 작성해줘" 요청
  • 3카메라 무브먼트 명시 (slow zoom in, pan right 등)
  • 4날씨·조명·시간대 조건 추가
  • 5영어 프롬프트 최종 정리 (100자 내외)
🎞️

Runway / Kling / Pika 영상 생성

STEP 3 · AI 영상 생성 도구

  • 1Nanobanana 이미지를 도구에 업로드
  • 2ChatGPT 프롬프트 입력칸에 붙여넣기
  • 3영상 길이: 4초 또는 8초 선택
  • 4Motion Strength: 중간~강 (3~4단계)
  • 5Generate → 결과 확인 후 최적 클립 저장
  • 6필요시 재생성 (Credits 관리 주의)
✂️

CapCut 9단계 편집 워크플로우

STEP 4 · 최종 편집 완성

  • 1새 프로젝트 생성 (9:16 세로 / 16:9 가로)
  • 2AI 영상 클립 순서대로 타임라인 배치
  • 3클립 간 트랜지션 추가 (Fade / Dissolve)
  • 4책 원문 자막 추가 (감성 폰트 선택)
  • 5배경음악 추가 (저작권 프리 음원)
  • 6색보정 LUT 적용 (Cinematic / Moody)
  • 7볼륨 밸런스 조정 (음악 -12dB 권장)
  • 8시작·끝 페이드 아웃 효과 적용
  • 91080p / 60fps 고화질로 최종 내보내기
